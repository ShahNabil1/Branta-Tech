# Homepage section rules
- Homepage hero content lives in the Home page's hero page_section (config: secondary_cta, capabilities, media_items by role), read via getHomeHero with the publishable key; src/lib/hero.ts holds shared parsing — no hero table.
- Homepage Capability Explorer lives in the Home page's capability_explorer page_section (config: default_key, items[] with video-first media {type,url,poster_url,alt,autoplay,loop,muted}, service_ids, related_labels fallback); only the active, in-view tab mounts a player; src/lib/capabilities.ts holds parsing — no capability table.
- Homepage AI Image showcase lives in the Home page's ai_image_showcase page_section (config: media_items, optional before_after_pair, layout_variant), parsed by src/lib/ai-image.ts and read via getAiImage; falls back to published portfolio image media when config has no images.
- Homepage Web & Software showcase lives in the Home page's web_software_showcase page_section (config: promo film, capabilities, work options, project_ids) read via getWebSoftware; its work area lists only published projects linked to web/software services or hand-picked, never the promo film.
- Remaining closing data (client_logos; final_cta reused by About if re-added) are Home page_sections read together by getHomeClosing; src/lib/home-closing.ts parses config — client logos hide publicly until real logos exist, insights teaser shows up to max_items published posts (via getInsights), else an empty note.
- Homepage media uses one model (src/lib/section-media.ts media_items in section config), one public renderer (components/media/SectionMedia.tsx) and one admin editor (admin/SectionMediaEditor.tsx); new section media must reuse them.
