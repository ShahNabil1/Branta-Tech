# Homepage section rules
- Homepage hero content lives in the Home page's hero page_section (config: secondary_cta, capabilities, media_items by role), read via getHomeHero with the publishable key; src/lib/hero.ts holds shared parsing — no hero table.
- Homepage Capability Explorer lives in the Home page's capability_explorer page_section (config: default_key, items[] with media, service_ids, related_labels fallback); src/lib/capabilities.ts holds parsing — no capability table.
- Homepage Featured Work reads published portfolio_projects (featured first, then sort_order/recency) via getFeaturedWork with the publishable key; presentation options live in the Home page's featured_work page_section config — never copy project data into config.
- Homepage AI Film showcase reads published video/vimeo portfolio projects via getAiFilm (manual project_ids in the ai_film_showcase section config first, else film-related projects); config stores only options and IDs.
- Homepage AI Image showcase lives in the Home page's ai_image_showcase page_section (config: media_items, optional before_after_pair, layout_variant), parsed by src/lib/ai-image.ts and read via getAiImage; falls back to published portfolio image media when config has no images.
- Homepage Web & Software showcase lives in the Home page's web_software_showcase page_section (config: promo film, capabilities, work options, project_ids) read via getWebSoftware; its work area lists only published projects linked to web/software services or hand-picked, never the promo film.
- Homepage AI Automation showcase lives in the Home page's automation_showcase page_section (config: default_key, use_cases[] with ordered nodes {label, kind}, outcomes); src/lib/automation.ts holds parsing, getAutomation reads it — workflow is pure HTML/CSS, no animation library, no automation table.
- Closing homepage sections (process, client_logos, insights_teaser, careers_teaser, final_cta) are Home page_sections read together by getHomeClosing; src/lib/home-closing.ts parses config — client logos hide publicly until real logos exist, insights show an empty note until a posts system exists.
